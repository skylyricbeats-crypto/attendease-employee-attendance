# AttendEase Repository Contents

## Website source

- `website/index.html` — main HTML shell
- `website/style.css` — responsive styling and layout
- `website/app.js` — dashboard, employee data, portrait URLs, search/filter, attendance and leave workflow
- `website/build.sh` — static production build script
- `website/manus-routes.json` — managed website route manifest
- `website/README.md` — website run instructions

## Reports and evidence

- `lab-report/Lab_Report.pdf` — final PDF lab report
- `lab-report/Lab_Report.docx` — editable Word report
- `lab-report/Lab_Report.md` — Markdown source report
- `lab-report/screenshots/` — dashboard, employees, leave and mobile screenshots

## Portraits

The synthetic employee portrait URLs are connected in `website/app.js`. They are fictional AI-generated demo portraits stored by the managed website platform; no real-person photographs are included.
