# AttendEase Complete Project

This package contains the updated Employee Attendance & Leave Management System website and its lab report.

## Website
Open `website/index.html` locally, or visit the published version:
https://attendease-fg9aeagt.manus.space

The website uses HTML, CSS and vanilla JavaScript. It includes the synthetic portrait URLs connected to the managed website storage, employee search/filtering, attendance records, leave requests and localStorage persistence.

## Lab report
Open the PDF for submission or edit the DOCX version first. Replace the blank student name, ID, course and date fields before submission.
